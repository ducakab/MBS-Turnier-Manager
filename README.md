# MBS-Turnier-Manager
Turniere eines Pool-Billard Vereins

## 🎱 Über das Projekt

**MBS Turnier Manager** ist eine Single Page Application (SPA) für die Verwaltung von Pool-Billard-Turnieren. Die gesamte Anwendung ist in einer einzigen HTML-Datei implementiert und bietet:

- 🏆 **Admin-Manager**: Vollständige Turnier- und Spielerverwaltung
- 📊 **Scoreboards**: Live-Anzeigetafeln für Matches
- 🎥 **OBS-Overlays**: Streaming-Overlays für Broadcasting
- ⚡ **Real-time Updates**: Live-Synchronisation über Firebase

## 🛠️ Tech Stack

- **Frontend**: Vanilla JavaScript (ES6+), HTML5, Tailwind CSS
- **Backend**: Firebase 11.6.1 (Auth, Firestore, Real-time Database)
- **Design**: Glass/Neon Design-System mit Dark Theme
- **Libraries**: FontAwesome, Confetti.js
- **AI**: Google Gemini API
